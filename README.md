# 📚 Online Library Management System

A modern, glassmorphism-themed web application for managing library books with Role-Based Access Control (RBAC) and Firebase integration.

## ✨ Features
- **User Authentication:** Secure Login and Registration powered by Firebase Auth.
- **Role-Based Access Control (RBAC):**
  - **Admin:** Full CRUD permissions (Add, Edit, Delete, View books).
  - **General Users:** Read-only access to view and search books.
- **Real-time Database:** Firestore Database integration for dynamic book management.
- **Interactive UI:** Responsive layout with live search filtering and glassmorphic styling.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Backend / Database:** Firebase Authentication & Firestore
